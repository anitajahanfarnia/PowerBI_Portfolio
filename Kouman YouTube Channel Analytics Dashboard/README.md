Kouman YouTube Channel Analytics Dashboard

This project focuses on analyzing the performance of the Kouman YouTube channel and exploring its key performance indicators (KPIs) using Power BI.

Data Collection and Preparation:
- Created an API Key in Google Cloud Console and enabled the YouTube Data API v3.
- Retrieved public channel, playlist, and video data using the YouTube Data API.
- Extracted and processed the required data using Python and exported it into CSV files.
- Cleaned, transformed, and prepared the data for Power BI.
Tools and Dashboard Features:
- Power Query: Data cleaning, transformation, and preparation.
- DAX: Creating calculated measures and analytical KPIs.
- Gregorian to Persian Calendar Conversion: Displaying dates using the Persian calendar.
- Persian Font Integration: Ensuring proper Persian text rendering and dashboard readability.
- Hamburger Navigation Menu: Implemented using Page Navigation, Bookmarks, and the Selection Pane.
The dashboard consists of two pages and provides insights into channel performance, video views and engagement, playlist performance, and estimated revenue
