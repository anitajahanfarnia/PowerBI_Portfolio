METZ 

Project Overview:

This project focuses on analyzing and monitoring Accounts Receivable (AR) for METZ Italy using Power BI.

The financial data related to accounts receivable was reviewed and prepared to provide better insights into outstanding balances, overdue and not-yet-due receivables, and payment collection performance.
Project Objectives
- Analyze the overall Accounts Receivable position.
- Distinguish between overdue and not-yet-due receivables.
- Examine invoice status and payment-related information.
- Enable financial monitoring through an interactive dashboard.
- Identify overdue receivables and support improvements in the accounts receivable management process.
Tools & Technologies
- Power BI: Dashboard development and data visualization
- Power Query: Data cleaning and preparation
- DAX: Calculations and analytical metrics
- Microsoft Excel: Data source
- Microsoft PowerPoint: Dashboard layout and visual design
Data Preparation
The data preparation process included:
- Reviewing the structure and quality of raw data.
- Removing invalid and unnecessary records.
- Handling missing values.
- Correcting column data types.
- Creating required calculated columns.
- Preparing tables for analysis and reporting.
